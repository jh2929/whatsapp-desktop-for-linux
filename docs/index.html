WhatsApp Desktop

Cliente nativo de WhatsApp Web para Linux. Ligero, rápido y sin dependencias innecesarias.

Rust + Tauri v2 WebKitGTK nativo 13 MB MIT License

Sin Electron, sin Chromium empaquetado, sin trackers. Solo un webview nativo apuntando a web.whatsapp.com con notificaciones nativas y soporte de bandeja del sistema.

No hay servidores intermedios, no hay cuentas externas, no hay recolección de datos. Tu sesión va directo a WhatsApp, igual que en el navegador.

Instalación rápida

# Debian / Ubuntu / Mint
sudo dpkg -i WhatsApp.Desktop_1.0.0_amd64.deb # Fedora / RHEL
sudo rpm -i WhatsApp.Desktop-1.0.0-1.x86_64.rpm # AppImage (cualquier distro)
chmod +x WhatsApp.Desktop_1.0.0_amd64.AppImage
./WhatsApp.Desktop_1.0.0_amd64.AppImage

Después de instalar, abre la app, escanea el código QR con tu teléfono y listo.
